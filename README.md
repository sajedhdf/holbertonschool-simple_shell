# Simple Shell

## Description

Simple Shell is a basic UNIX command interpreter written in C.
It executes commands entered by the user, similar to `/bin/sh`.

## Compilation

```
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o hsh
```

## Usage

Run the shell:

```
./hsh
```

Example:

```
($) /bin/ls
main.c shell.c
($)
```
